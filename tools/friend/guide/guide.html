Why does Yousif need this?

His university project is a tool that helps investigators figure out what a harmful program did on a computer, by following the traces it leaves behind.

The tricky part: computers are busy all the time. Programs start, connect and stop constantly, even when you do nothing. To tell "suspicious" from "just a normal busy laptop", the project needs to know how busy normal laptops are. Like a doctor who needs to know a normal heart rate before calling one too fast.

Your laptop gives him that "normal heart rate". Only counts, like "400 programs started per hour", never what those programs were.

Your privacy, in four promises

✓

Everything it records stays on your laptop. Nothing is uploaded. It works without internet.

✓

You only ever send one small file of numbers, and you read it first. No names, websites, files or times.

✓

Pause any time for an hour. While paused, Analyst Lab only counts that "something happened", never what. (Windows' own Sysmon log, which only administrators can open, still notes details as it always does; uninstalling empties it.)

✓

"Uninstall everything" removes it all: the program, its background task, everything it recorded, and Sysmon if Setup turned it on. (That's also why you export first.)

  1. Double-click Setup-AnalystLab.exe

    It's in the same folder as this guide.

  2. If Windows says "Windows protected your PC"

    Click More info, then Run anyway. This appears because it's a student program, and the "signature" that would make Windows trust it costs money.

    Windows protected your PC Microsoft Defender SmartScreen prevented an unrecognized app from starting… More info
    Run anywayDon't run

    (A drawing: yours may look slightly different. The yellow outlines show what to click.)

  3. "Do you want to allow this app to make changes?" → Yes

    User Account Control
    Do you want to allow this app to make changes to your device?Setup - Analyst Lab
    YesNo

    Setup needs this once, to turn on Microsoft's recording tool (Sysmon, part of Windows). If your account isn't an admin, Windows asks for an admin password here.

  4. Read the short "before you install" page → Next → Install

    It can take a few minutes. If it asks to restart your laptop, say yes; it finishes by itself afterwards.

  5. Keep "Open Analyst Lab" ticked → Finish

    A small window opens and, after about 20 seconds, checks by itself that recording works. You should see this:

    • 1Green "Collecting" = all good. You can close the window; recording continues in the background.
    • 2Progress: "Day 1 of 7". A day counts when your laptop is switched on that day, so days it stays off don't count. Take your time.
    • 3Export my statistics: you'll use it twice, on day 1 and day 7 (see below).
    • 4Pause for 1 hour: whenever you want privacy. It resumes by itself.
    • 5Self-test: four PASS lines mean everything is recorded. You can run it again any time.
    • 6Uninstall everything: don't touch it until the very end. It deletes all recordings for good (see the red box below).
That's it. Now forget about it and use your laptop as usual. To check on it, open Analyst Lab from your Desktop.

Before you uninstall: read this

Uninstalling permanently deletes everything Analyst Lab recorded. There is no undo, and nobody (not even Yousif) can get it back.

  • ☐I clicked Export my statistics on day 7
  • ☐I sent that file to Yousif
  • ☐Yousif confirmed he received it

All three ticked? Then open Analyst Lab → Uninstall everything → Yes. (Or Windows Settings → Apps → Analyst Lab → Uninstall.)

Good to know: your exported statistics files on the Desktop are not deleted; they're yours. Uninstall removes the recorder, its background task, all recordings, and Microsoft's Sysmon with its log (if Setup turned it on; Windows finishes switching Sysmon off at your next restart).

What's in the file you send

✓ In it (numbers only)

  • How many days and hours it recorded
  • How many minutes you paused
  • How many programs started, connections, website-name lookups, new program files… in total and per hour
  • The same counts for each hour, without the date or time
  • Health numbers (did it miss anything, did the self-test pass)

✗ Never in it

  • Names of programs or apps
  • Websites, addresses, file names
  • When you used your laptop
  • What you typed, your passwords, your screen
  • Contents of any file or message

A built-in check refuses to write the file if anything other than its own labels and numbers would get in. And you read it before sending anyway.

Questions people ask

What exactly does it record on my laptop?

Using Microsoft's own tool Sysmon: which programs start and close, which program connects where, which website names get looked up, and new or deleted program files (plus files in Downloads and Startup). It does not record what you type, your screen, or what's inside files, messages or web pages. It does note the exact command that started each program, which can include a file's name (for example a document you opened). All of it stays on your laptop; only the numbers file is ever sent, by you, and that file contains none of these details.

Will it slow down my laptop?

No. On Yousif's laptop the recorder uses well under 1% of the processor and around 12 MB of memory, less than a single browser tab.

How much space does it use?

Usually under 1 GB in total, including Windows' own Sysmon log. Finished days are compressed automatically, and uninstalling frees all of it.

Does it need internet?

No. Only on older versions of Windows, Setup downloads Sysmon once from Microsoft.

The window shows a red message

Restart your laptop and open Analyst Lab again. If it's still red, take a screenshot of the window (it shows nothing personal) and send it to Yousif.

Setup showed an error

Send Yousif the file C:\ProgramData\AnalystLab\setup-log.txt. It contains no personal information, only what Setup did.

I want to stop early

No problem at all. Export your statistics first (whatever days you have still help), send them, and only then uninstall: uninstalling deletes the recordings, so it can't be exported afterwards.
